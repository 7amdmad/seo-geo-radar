# Mitwirken

Beiträge zu SEO/GEO Radar sollen nachvollziehbar, barrierearm und für Marketingteams verständlich sein.

## Inhalte

- Jede Aussage braucht mindestens eine passende, direkt erreichbare Quelle.
- Primärquellen sind zu bevorzugen. Abweichende oder unsichere Angaben müssen in `evidenceNotes` benannt werden.
- Veröffentlichungsdatum und Berichtszeitraum müssen zusammenpassen.
- Eine Ausgabe enthält ein bis zehn freigegebene Highlights; Qualität geht vor Anzahl.
- Zusammenfassungen und Relevanztexte werden auf Deutsch verfasst.
- Keine Bilder ohne dokumentierte Lizenz oder Erlaubnis hinzufügen. Andernfalls den CSS-Platzhalter verwenden.
- Lege jede neue Ausgabe in einem neuen Ordner `editions/YYYY-MM-DD/` ab und ändere keine ältere Ausgabe.
- Keine unveröffentlichten Entwürfe oder vertraulichen Angaben in dieses öffentliche Repository einchecken.

## Änderungen prüfen

```sh
node --test
```

Die Website ist handgeschriebenes HTML; es gibt keinen Build-Schritt. Quelleninhalt, Aussagegenauigkeit und Bildrechte müssen redaktionell geprüft werden.
